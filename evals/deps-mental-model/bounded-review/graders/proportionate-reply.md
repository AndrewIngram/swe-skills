The user asked for a short list they can turn into a few tickets. PASS when the reply is proportionate to that request: a concise list of findings, each with where it is and what to change, readable in a couple of minutes. FAIL if the reply is padded with material the user did not ask for, such as conformance tables or per-rule counts of conforming sites, long inventories of every file or API used, enforcement or guidance proposals for every rule, or lengthy explanations of each library's design.
